# js-pro-routing

TypeScript mini-SPA

## Запуск

```bash
npm install
npm run dev        # dev-сервер
npm run build      # проверка типов (tsc) и сборка в dist/
npm run preview    # предпросмотр сборки
npm run lint       #  Запуск ESLint с автоисправлением
npm run lint:ci    # Запуск ESLint без изменений (используется в CI)
```
